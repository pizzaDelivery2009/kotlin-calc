# Kotlin Calculator

A calculator made on kotlin.

## Functions

- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling
- Invalid operation handling


## How to run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Run `Main.kt`.

## Example

```text
=== Kotlin Calculator ===

Enter first number: 10
Enter operation (+, -, *, /): *
Enter second number: 5

Result: 50.0
