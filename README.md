How to use it?

Click Open the Calculator above. It opens in a new page and loads in a few seconds.
Tap the number buttons and pick an operation (+, -, ×, ÷).
Press = to see the result.
Button	What it does
C	Clears everything and starts over
Backspace icon	Deletes the last digit
.	Adds a decimal point
=	Shows the result

Dividing by zero shows Error instead of crashing. Press C to continue.

Tip: the first load downloads the app, so it may take a moment. After that it starts faster.
